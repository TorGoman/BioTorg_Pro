## 🚀 طرق الاستخدام والتشغيل

يوفر المشروع خيارين للتشغيل، سواء كنت **مستخدماً/شركة** تريد البرنامج الجاهز بنقرة واحدة، أو **مطوّراً** تريد فحص الكود والتعديل عليه:

### 1️⃣ الخيار الأول: التثبيت المباشر بنقرة واحدة (للمستخدمين والشركات)
البرنامج متاح كملف تثبيت احترافي قياسي لويندوز (Installer)، جاهز للعمل مباشرة دون الحاجة لأي معرفة برمجية أو تثبيت لبايثون:
1. حمّل ملف التثبيت المباشر: **[BioTorg_Pro_Setup_v2.2.1.exe (اضغط هنا للتحميل المباشر)](https://github.com/TorGoman/BioTorg_Pro/raw/main/BioTorg_Pro_Setup_v2.2.1.exe)**.
2. شغّل المثبت، واتبع خطوات معالج التثبيت العربي البسيط.
3. سيتم إنشاء اختصار رسمي بأيقونة درع البصمة الحيوية على سطح المكتب وقائمة Start ليعمل البرنامج فوراً.

---

### 2️⃣ الخيار الثاني: التشغيل من الكود المصدري المفتوح (للمطورين)
المشروع مفتوح المصدر بالكامل (Open Source) تحت رخصة **MIT**. يمكنك استنساخ الكود وتعديله وبناء حزمتك الخاصة:

```bash
# 1. استنساخ المستودع
git clone https://github.com/TorGoman/BioTorg_Pro.git
cd BioTorg_Pro

# 2. تثبيت المكتبات المطلوبة
pip install -r requirements.txt

# 3. تشغيل البرنامج مباشرة
python attendance_gui.py
# أو يمكنك النقر المزدوج على ملف RUN.bat
```

#### 📦 بناء ملف التثبيت التنفيذي (EXE Installer) بنفسك:
```bash
python build_installer.py
```
*سيقوم السكريبت بتجميع التطبيق عبر PyInstaller ثم تحويله إلى ملف تثبيت رسمي عبر Inno Setup تلقائياً.*

## 🖼️ استعراض شاشات البرنامج الحقيقية (Real UI Showcase)

> **ملاحظة:** جميع الصور أدناه حقيقية 100% ومأخوذة مباشرة من البرنامج مع استخدام **بيانات وهمية نموذجية** للشرح وتوضيح الإمكانيات.

### 1️⃣ التقرير اليومي الذكي وبطاقات الـ KPI
![التقرير اليومي](assets/screenshots/01_daily_attendance.png)
* متابعة لحظية للحاضرين، المتأخرين، الغائبين، ومن نسوا تسجيل الانصراف مع فلاتر فرز سريعة وزر لتسجيل المأموريات والأعذار بنقرة واحدة.

---

### 2️⃣ مسير الرواتب والـ HR فائق السرعة
![مسير الرواتب والـ HR](assets/screenshots/03_hr_payroll.png)
* احتساب شامل وفوري لمستحقات مئات الموظفين في أقل من 0.35 ثانية: الراتب الأساسي، البدلات، المكافآت، خصم الغياب، خصم التأخير بالشرائح أو الدقائق، احتساب الإضافي، وصافي الراتب المستحق مع تصدير تقارير Excel معتمدة.

---

### 3️⃣ الملخص الشهري والدوري التراكمي
![الملخص الشهري](assets/screenshots/02_monthly_summary.png)
* كشف حساب تراكمي كامل لكل موظف على مدار الشهر متضمناً أيام الحضور والغياب، ودقائق التأخير، ومتابعة رصيد ساعات الاستئذان الشهرية الموحدة.

---

### 4️⃣ إعدادات العمل والورديات والجزاءات
![إعدادات العمل والورديات](assets/screenshots/04_shift_settings.png)
* مرونة كاملة في تحديد مواعيد الوردية، فترات سماح الحضور والانصراف، شرائح خصم التأخير المتدرجة، وضبط الإجازات الأسبوعية العامة والخاصة بكل موظف.

---

### 5️⃣ سجل الحركات الخام وفلترة البصمات الوهمية
![سجل الحركات الخام](assets/screenshots/05_raw_punches.png)
* فحص الحركات المسحوبة من جهاز البصمة وفلترة البصمات المكررة والوهمية المسجلة خلال أقل من 60 ثانية (*Ghost / Double Punches*) لمنع أي تضارب.

## 📂 هيكل المشروع البرمجي (Project Architecture)

```text
BioTorg_Pro/
├── attendance_gui.py        # الواجهة الرسومية الكاملة (CustomTkinter)
├── attendance_engine.py     # محرك معالجة الحضور ومسير الرواتب (HR Engine)
├── updater.py               # محرك التحديث السحابي التلقائي
├── build_installer.py       # نظام تجميع وبناء مثبت البرامج (PyInstaller + Inno Setup)
├── BioTorg_Pro.spec         # ملف تعريف ومواصفات PyInstaller
├── BioTorg_Pro_Setup.iss    # سكربت مترجم Inno Setup
├── requirements.txt         # المكتبات البرمجية المطلوبة
├── LICENSE                  # رخصة MIT مفتوحة المصدر
├── version.json             # بيانات الإصدار وسجل التغييرات
├── BioTorg_Pro_Setup_v2.2.1.exe # مثبت الويندوز الجاهز للتحميل المباشر
└── assets/                  # الأيقونات، لقطات الشاشة، وكود الدعم
```
